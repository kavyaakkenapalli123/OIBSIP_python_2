# Password Generator 🔐

A simple and secure Password Generator application built using Python.  
This project generates strong random passwords with customizable length and character combinations.

---

## 📌 Features

- Generate strong random passwords
- Custom password length
- Includes:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- User-friendly interface
- Fast and lightweight

---

## 🛠️ Technologies Used

- Python
- Random Module
- String Module
- Tkinter (if GUI project)

## 📖 How It Works

The application uses Python’s built-in:
- `random` module for random selection
- `string` module for character sets

The password is generated by randomly combining:
- Alphabets
- Digits
- Symbols
